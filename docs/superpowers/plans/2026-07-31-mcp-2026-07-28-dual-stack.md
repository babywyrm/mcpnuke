# MCP 2026-07-28 Dual-Stack Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let mcpnuke enumerate and scan MCP servers that speak the stateless `2026-07-28` spec, while continuing to scan legacy handshake-based servers, auto-detecting which one a target uses.

**Architecture:** A new `mcpnuke/core/protocol.py` owns protocol-mode constants, per-request routing headers (`Mcp-Method`, `Mcp-Name`, `MCP-Protocol-Version`), and `_meta` client-identity injection. `HTTPSession` takes a `protocol_mode` and builds request headers/params through that module. `enumerator.py` gains a `negotiate_protocol()` step that probes `initialize` → `server/discover` → bare `tools/list` and records the winning mode on `TargetResult`, which downstream checks and reporting can read.

**Tech Stack:** Python 3.11+, `httpx`, `pytest`, `uv`.

---

## Background: what changed in the spec

Source: https://blog.modelcontextprotocol.io/posts/2026-07-28/

Relevant to this plan:

- The `initialize` / `notifications/initialized` handshake is **retired** (SEP-2575). Each request is self-describing and carries protocol version, client identity, and capabilities in `_meta`.
- The `Mcp-Session-Id` header is **retired** (SEP-2567).
- A new optional `server/discover` RPC returns server capabilities for clients that want them up front.
- Streamable HTTP requests **must** carry `Mcp-Method` and `Mcp-Name` headers (SEP-2243) so gateways can route/authorize on headers.
- Legacy HTTP+SSE transport is deprecated with a twelve-month offramp.

Because the deprecation window is twelve months, real targets will be mixed for a long time. mcpnuke must speak both.

## Current behavior this plan changes

- `mcpnuke/core/constants.py:7` pins `MCP_PROTOCOL_VERSION = "2024-11-05"`.
- `mcpnuke/core/enumerator.py:75` unconditionally calls `initialize` and returns early (with a `HIGH` "No response to MCP initialize" finding) when there is no result. Against a stateless-only server this yields **zero tools**, which silently disables every downstream check.
- `mcpnuke/core/session.py:272-282` attaches `Mcp-Session-Id` on every `HTTPSession` request.

## File structure

- **Create** `mcpnuke/core/protocol.py` — protocol-mode constants, routing headers, `_meta` injection. Single responsibility: "what does a request look like in mode X".
- **Modify** `mcpnuke/core/session.py` — `HTTPSession` becomes mode-aware. `MCPSession` (legacy SSE) is intentionally left alone; SSE is deprecated by the new spec.
- **Modify** `mcpnuke/core/enumerator.py` — add `negotiate_protocol()`, use it before enumerating, skip `notifications/initialized` in stateless mode.
- **Modify** `mcpnuke/core/models.py` — add `protocol_mode` to `TargetResult`.
- **Modify** `mcpnuke/cli.py` — add `--protocol-mode`.
- **Create** `tests/test_protocol.py`, `tests/test_protocol_negotiation.py`.

## Out of scope (follow-ups, not this plan)

These are detection features, not compatibility, and belong in a separate plan:

- `Mcp-Method` / `Mcp-Name` header-vs-body mismatch check (authorize-on-header, execute-on-body confused deputy).
- List cache-poisoning checks around `ttlMs` / `cacheScope` (SEP-2549).
- MRTR `input_required` / `inputResponses` abuse checks (SEP-2322).
- RFC 9207 `iss` validation and CIMD-vs-DCR auth checks (SEP-2468, SEP-2352).
- A finding for servers still on deprecated Roots/Sampling/Logging or legacy SSE.

```python
"""MCP protocol-mode handling for legacy and stateless (2026-07-28) servers.

The 2026-07-28 spec retires the initialize/initialized handshake and the
Mcp-Session-Id header. Requests are self-describing: client identity travels
in ``params._meta`` and routing information travels in HTTP headers.

Reference: https://blog.modelcontextprotocol.io/posts/2026-07-28/
"""

from __future__ import annotations

from typing import Any

from mcpnuke import __version__

LEGACY: str = "legacy"
STATELESS: str = "stateless"
AUTO: str = "auto"

PROTOCOL_MODES: frozenset[str] = frozenset({LEGACY, STATELESS, AUTO})

MCP_PROTOCOL_VERSION_STATELESS: str = "2026-07-28"

CLIENT_INFO_META_KEY: str = "io.modelcontextprotocol/clientInfo"


def client_info_meta() -> dict[str, Any]:
    """Build the ``_meta`` client-identity block for a stateless request."""
    return {CLIENT_INFO_META_KEY: {"name": "mcpnuke", "version": __version__}}


def inject_meta(params: dict[str, Any] | None, mode: str) -> dict[str, Any]:
    """Return a copy of *params* with stateless ``_meta`` added when required."""
    out: dict[str, Any] = dict(params or {})
    if mode != STATELESS:
        return out
    meta: dict[str, Any] = dict(out.get("_meta") or {})
    meta.update(client_info_meta())
    out["_meta"] = meta
    return out
```

```python
_NAME_PARAM_KEYS: tuple[str, ...] = ("name", "uri")


def _header_safe(value: str) -> str:
    """Strip CR/LF so a hostile tool name cannot inject extra headers."""
    return value.replace("\r", "").replace("\n", "").strip()


def routing_headers(
    method: str,
    params: dict[str, Any] | None,
    mode: str,
) -> dict[str, str]:
    """Build the stateless routing headers for a request.

    Returns an empty dict in legacy mode so callers can unconditionally merge.
    """
    if mode != STATELESS:
        return {}

    headers: dict[str, str] = {
        "MCP-Protocol-Version": MCP_PROTOCOL_VERSION_STATELESS,
        "Mcp-Method": _header_safe(method),
    }

    for key in _NAME_PARAM_KEYS:
        value = (params or {}).get(key)
        if isinstance(value, str) and value.strip():
            headers["Mcp-Name"] = _header_safe(value)
            break

    return headers
```

```python
def negotiate_protocol(
    session,
    result: TargetResult,
    mode: str = AUTO,
    verbose: bool = False,
    log=None,
) -> str:
    """Determine whether *session* speaks the legacy or stateless protocol.

    Probes ``initialize`` (legacy handshake), then ``server/discover``, then a
    bare ``tools/list`` (both stateless). Returns the winning mode, or ``""``
    when the server answered none of them. Sets ``result.protocol_mode`` and
    ``session.protocol_mode`` as a side effect.
    """
    _log = log or (lambda msg: None)

    if mode in (AUTO, LEGACY):
        if verbose:
            _log("  [dim]Sending initialize...[/dim]")
        resp = session.call("initialize", MCP_INIT_PARAMS, retries=3)
        if resp and "result" in resp:
            result.server_info = resp["result"]
            result.protocol_mode = LEGACY
            session.protocol_mode = LEGACY
            return LEGACY
        if mode == LEGACY:
            return ""

    # Stateless: capabilities are optional, so a failed discover is not fatal.
    session.protocol_mode = STATELESS

    if verbose:
        _log("  [dim]Trying stateless server/discover...[/dim]")
    resp = session.call("server/discover", None, retries=2)
    if resp and "result" in resp:
        result.server_info = resp["result"]
        result.protocol_mode = STATELESS
        info = resp["result"].get("serverInfo", {})
        result.add(
            "auth",
            "HIGH",
            "Unauthenticated MCP server/discover accepted",
            f"Server '{info.get('name','?')}' v{info.get('version','?')} "
            f"disclosed capabilities to an anonymous caller via server/discover",
            evidence=json.dumps(resp["result"], indent=2)[:500],
            skip_transports=["stdio"],
            lane=5,
            transport="A",
        )
        return STATELESS

    if verbose:
        _log("  [dim]Trying stateless tools/list without discovery...[/dim]")
    resp = session.call("tools/list", None, retries=2)
    if resp and "result" in resp:
        result.protocol_mode = STATELESS
        return STATELESS

    session.protocol_mode = LEGACY
    return ""
```

```python
        result.timings["enumerate"] = time.time() - t0
        return

    r = result.server_info
    info = r.get("serverInfo", {})
    caps = r.get("capabilities", {})

    if verbose:
        server_name = info.get("name", "?")
        server_version = info.get("version", "?")
        proto = r.get("protocolVersion", "?")
        _log(f"  [dim]Server: {server_name} v{server_version}  protocol={proto} mode={mode}[/dim]")
        cap_list = list(caps.keys()) if caps else ["none"]
        _log(f"  [dim]Capabilities: {', '.join(cap_list)}[/dim]")

    if mode == LEGACY:
        result.add(
            "auth",
            "HIGH",
            "Unauthenticated MCP initialize accepted",
            f"Server '{info.get('name','?')}' v{info.get('version','?')} "
            f"accepted initialize with no credentials",
            evidence=json.dumps(r, indent=2)[:500],
            skip_transports=["stdio"],
            # The "anybody can initialize" failure is a Lane 5 (anonymous)
            # finding: it describes what a pre-auth caller can do.
            lane=5,
            transport="A",
        )
        session.notify("notifications/initialized")
        time.sleep(0.5)
```
